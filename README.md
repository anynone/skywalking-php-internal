SkyAPM PHP SDK (C++ Internal Fork)
==========

> **项目声明**
>
> 本项目是原 [SkyAPM/SkyAPM-php-sdk](https://github.com/SkyAPM/SkyAPM-php-sdk) 的 C++ 实现版本，仅供内部使用，持续进行维护以保证现有功能稳定运行，但**不再新增任何功能**。
>
> 如果你是新项目，请使用 SkyWalking 官方基于 Rust 的 PHP 扩展：[apache/skywalking-php](https://github.com/apache/skywalking-php)。

## 支持的组件
1. CURL
1. PDO
1. Mysqli
1. Yar Client (version > 2.0.4)
1. Yar Server
1. GRPC Client
1. Predis Client
1. Redis Extension
1. Memcache Extension
1. RabbitMQ
1. Swoole
1. Hyperf
1. Swoft
1. Tars-php
1. LaravelS
